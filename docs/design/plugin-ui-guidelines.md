# 轻作插件界面视觉规范

本规范适用于轻作底座内的官方与第三方插件。插件应像一个嵌进工作台的专业工具，而不是另一套独立产品。规范以信息密度、可读性和长期一致性优先于装饰效果。

## 视觉方向

- 工作区域保持纯净白色 `#ffffff`，用边框、留白和轻量中性表面建立层级。
- 顶栏、侧栏等窗口外壳可以使用浅灰 `#f2f3f0`，与白色工作区域形成安静分区。
- 墨绿 `#28654a` 只用于主操作、当前选择、焦点与成功状态，不大面积铺色。
- 不使用品牌 Hero、英文 Eyebrow、启动页、独立 Logo 区或重复的页面标题。
- 不使用玻璃拟态、彩色渐变、光晕、装饰性大阴影和超大圆角。
- 不使用紫色、靛蓝、霓虹色或与轻作无关的品牌主色。

## 字体与字号

使用系统中文无衬线字体：

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI",
  "PingFang SC", "Microsoft YaHei", sans-serif;
```

- 页面标题：`22px / 650`，行高约 `1.25`，字距 `-0.25px`。
- 区块标题：`14px / 650`，行高约 `1.4`。
- 正文与控件：`13px`，输入框、按钮、下拉框保持一致。
- 表单标签：`12.5px / 600`。
- 辅助说明：`12px`，次要信息不得低于 `11px`。
- `10–11px` 仅用于版本号、状态徽标等非关键元数据，不能承载操作说明。

不要把整套界面压到 `11–12px` 来换取“紧凑”。紧凑来自边距和间距，不来自牺牲可读性。

## 密度与布局

- 工具页面内边距：`24px 28px 40px`。
- 小屏工具页面内边距：`16px 14px 28px`。
- 页面标题区底部间距：`16px`；区块标题区底部间距：`14px`。
- 卡片内边距：`16–18px`；列表行内边距：`10–14px`。
- 主网格间距：`12–14px`；表单控件间距：`12px`。
- 输入框、下拉框、按钮高度：`34–36px`。
- 导航项高度：`32–34px`，选中状态优先使用轻底色与清晰文字，不使用厚重描边。
- 主内容最大宽度以 `1180–1280px` 为参考；编辑器和多栏工作台可以占满可用宽度。
- 桌面双栏使用稳定的最小宽度；窄屏必须单栏堆叠，不允许横向滚动。

## 形状与层级

- 卡片圆角：`7–9px`。
- 输入框、按钮、页签圆角：`6px`。
- 状态徽标、紧凑标签圆角：`4–5px`。
- 圆形只用于头像、图标底座或明确的圆形控件。
- 普通卡片使用 `1px solid var(--qz-border)`；不使用多层阴影模拟浮起。
- 同一区域最多出现一种强调底色，不能层层嵌套浅绿卡片。

## 组件规则

- 一个区域只保留一个主操作；次要操作使用边框按钮或文本按钮。
- 表单始终提供可见标签，不能只依赖 placeholder。
- 错误、成功和警告状态必须同时提供文字或图标，不能只靠颜色。
- 空状态直接在白色工作区中表达，使用小图标、标题、一句说明和一个主操作；不要做成占满视口的大型插画页。
- 加载状态保持局部，不覆盖整个工具页面；已有内容不应因局部刷新而消失。
- 列表和表格优先使用分隔线与轻底色，不使用卡片套卡片。
- 图片、视频和音频结果必须有稳定的媒体舞台；没有结果时只显示简短占位说明。

## 响应式

至少覆盖以下宽度：

- `1440 × 1000`：标准桌面窗口。
- `1020px` 与 `940px`：多栏工作台切换为紧凑布局。
- `700px` 与 `620px`：工具页双栏改为单栏。
- `480px` 与 `420px`：最终移动宽度，按钮可换行，文字保持完整。
- `390 × 844`：必须无横向溢出，表单控件和主操作可用。

窄屏规则：

- 页面标题与模式徽标允许同一行，但副标题不能挤压主标题。
- 双列表单改为单列。
- 工具栏允许换行，不把图标或文字缩小到不可读。
- 凭据行、操作按钮可换行，但主次顺序不变。

## 主题与可访问性

- 同时支持浅色与深色模式；默认跟随系统，用户显式选择时以用户选择为准。
- 正文与背景、按钮文字与按钮底色必须满足 WCAG AA 对比度。
- 键盘焦点使用 `2px` 的 `--qz-focus` 外环，不能只用浅色边框。
- 保留现有业务 ID、ARIA 标签、快捷键和键盘操作。
- 动画只用于状态变化，持续 `120–200ms`；遵守 `prefers-reduced-motion`。

## 验收清单

- 工作区域在浅色模式下为纯白，不是暖白或灰白。
- 深色模式没有残留白块、黑字、固定浅色边框或不可读占位文字。
- `1440 × 1000` 与 `390 × 844` 均无横向溢出。
- 标题、标签、正文、辅助文字层级清楚，正文不被压到不可读字号。
- 圆角不超过 `9px`，重要卡片没有大阴影，页面没有重复设置入口。
- 现有功能、权限、凭据、网络与文件流程没有改变。
