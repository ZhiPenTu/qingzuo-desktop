# 轻作（Qingzuo）v0.2.2 设计

轻作是一张轻巧的工具工作台。主页、插件市场、插件管理、设置、更新和 LabelEdit 编辑器共享同一套视觉语言。

## 视觉规则

- 暖白背景 `#f7f8f4`、白色表面、墨绿主色 `#28654a`、正文 `#20312a`、次要文字 `#69756e`、边框 `#dfe5de`。
- 深色模式使用深绿灰背景、浅色文字和柔和薄荷绿主色，PDF 本身保留原始颜色。
- 使用系统中文无衬线字体。主标题 32px/650，页面标题 22px/600，正文 14px，导航与控件 13px，说明 12px；编辑器控件保持 12–14px。
- 208px 左侧导航，64px 顶栏，内容最大宽度 1100px。主页使用横向工具列表；市场使用两列插件卡片；管理页使用完整工具行。内容区域独立滚动。
- 主按钮为墨绿实底，次按钮为细边框；控件高度 36px，面板圆角 12px，图标使用 Lucide 统一线宽。选中项用浅绿色表面和清晰边框表示。
- 小屏导航保留图标及可访问名称，市场卡片改为单列，编辑器保留现有抽屉式文字与属性面板。

## 内容与交互

主页：标题「让日常工作，轻一点。」；独立工具盒插画与「开始你的下一件小事」；「浏览插件市场」入口；真实已安装工具列表和搜索。

市场：标题「让工作台，多一点可能。」；真实目录分类、搜索、插件介绍、折叠版本说明、已安装/更新/安装状态；加载、失败重试与空结果使用各自状态。

管理、设置与更新：沿用现有功能和权限流程，使用统一表面、分隔线、字体和按钮；外观使用浅色、深色、跟随系统选项。

编辑器：白色顶栏与工具栏，绿色选中区域，灰色画布；有编号的文字列表和紧凑属性表单；沿用实际 OCR、原尺寸 PDF、撤销与导出流程。

## 资源与生成记录

界面概念与独立主页插画使用内置 ImageGen 生成，界面文字与控件均使用 React 实现。应用图标使用矢量绘制，避免生成图在小尺寸下的边缘噪声。

图标构成：透明背景的墨绿圆角方块；象牙白折角文档从浅米色托盘中升起，文档上有两条墨绿粗线；右上角薄荷绿四角星芒表示「轻」；不含文字，轮廓在 16/32px 下仍可辨识。

插画提示词：透明背景、墨绿浅工具托盘，象牙白折角文档、浅绿色标签、四个手柄的裁切框；简洁轻微阴影；无文字与无关物体。

矢量源文件为 `desktop/icons/icon.svg`，由它渲染并编码出 `desktop/icons/icon.png`、macOS ICNS、Windows ICO（16–256px）以及 128px 的 UI PNG（`src/assets/qingzuo.png`、`site/assets/qingzuo.png`）。主页插画位于 `src/assets/workspace.png`。转换只缩放及编码，不重新绘制图像。

## 更新兼容性

应用显示名称与安装后的可执行文件为 Qingzuo，中文界面名称为轻作。沿用 `com.commerce.tools.desktop`、原用户数据目录与插件 ID。安装包继续采用 `CommerceTools-<version>-...` 文件名，使现有客户端仍能发现新版本。LabelEdit 插件升级到 0.1.1，使已安装的插件能够独立更新至新界面。
