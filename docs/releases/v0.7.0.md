# 轻作 Qingzuo v0.7.0

- 新增插件持久工作区：授权后可在本地管理文章、系列、发布内容和业务素材，支持原子写入、路径隔离与 `.aws` 预设包预览导入。
- 新增远程 MCP 能力连接：支持 Streamable HTTP、静态令牌和 OAuth 2.1 + PKCE，插件只能使用宿主授权且声明为只读的工具。
- 新增公众号连接与发布能力：支持账号验证、草稿创建、发布、状态查询和内容列表；AppSecret 保存在系统凭据库，发布前始终由宿主确认。
- 新增共享 AI 的文本输出上限与截断状态，以及图片批量生成直接写入工作区的受控流程。
- 插件 API / SDK 升级至 1.9.0，保持旧插件和原有调用方式兼容。
- 发布前增加微信正文 HTML、图片占位符和错误信息的边界校验，避免外部资源注入和本地路径泄露。

支持 macOS 15+ Apple Silicon、Windows 10+ x64。
