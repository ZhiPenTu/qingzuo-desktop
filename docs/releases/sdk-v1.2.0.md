# Plugin SDK 1.2.0

- 新增批量选图与输出目录授权，返回不透明标识。
- 新增助手会话、批次创建 / 查询 / 执行 / 取消 / 事件接口，支持后台任务与恢复。
- `ai.models({ source })` 支持官方 API 和共享 CLIProxyAPI 图片模型；省略参数仍使用官方接口，保持兼容。
- 新增 AI 权限、助手工具清单及工具参数校验；插件不得直接读取共享凭据或访问本机代理。
- 图像请求和响应解析由可信宿主完成；批次固定来源与型号，执行需要用户确认。

需要轻作 0.3.0 / 插件 API 1.2.0。现有 SDK 接口保持兼容；通过本 Release 的固定 `.tgz` 安装，不要求插件运行时安装 Node/npm。
