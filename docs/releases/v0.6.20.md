# 轻作 Qingzuo v0.6.20

- 新增市场工具「凭证管理」：集中保存多组 AppID 与 `APP_SecretKey`，支持别名、生产/沙箱环境、替换密钥、查看使用方和撤销授权。
- 其他工具可以在你确认后引用共享凭证，签名和请求由轻作在后台完成；工具页面看不到密钥，卸载工具或删除凭证会同时清理对应授权。
- 密钥使用系统安全存储加密后落盘。开发构建、应用身份变化或系统钥匙串状态变化时，macOS 可能再次询问钥匙串授权。
- 旧版明文密钥不再使用。升级后请重新填写 AI、抠图、Seedance、希音等工具中已保存的密钥；凭据管理和相关授权需要联网安装市场版工具后使用。
- 插件 API 与 SDK 升级到 1.7.0，增加共享凭证记录接口与 `network.request/sign` 的记录引用；原有字符串凭据调用继续兼容。

支持 macOS 15+ Apple Silicon、Windows 10+ x64。
