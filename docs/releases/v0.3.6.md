# 轻作 Qingzuo v0.3.6

- 修复 Windows 下导入未下载完整或损坏的 `.ecplugin` / `.zip` 插件包时直接透出 `ADM-ZIP: Invalid or unsupported zip format. No END header found` 英文异常的问题，统一返回清晰的中文提示。
- 支持导入 Windows 资源管理器压缩生成的单层顶层目录 `.zip` 插件包，移除交互式导入与大包解压时的 30 秒内核请求超时限制，并校验下载流的完整性。
- 清洗 Electron IPC 调用异常前缀，并将轻作应用更新控制统一整合进“设置 -> 运行环境”卡片。
- 保留 Harness / DeepSeek 内核 `v0.2.1-alpha.1` 的版本检查和组件更新能力。

支持 macOS 15+ Apple Silicon、Windows 10+ x64。插件 API / SDK 仍为 1.2.0；保留现有配置和已安装插件。
