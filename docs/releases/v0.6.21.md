# 轻作 Qingzuo v0.6.21

- 新增「凭证管理」：集中保存多组 AppID 与 `APP_SecretKey`，支持别名、生产/沙箱环境、替换密钥、查看使用方和撤销授权。其他工具在你确认后可以引用共享凭证，工具页面看不到密钥。
- 新增文件下载能力：其他工具可以请求下载公开 HTTPS 直链；服务器支持断点续传时使用最多 4 路连接，不支持时自动改为普通下载。暂停后可继续，应用重启后未完成任务也会恢复。
- 下载任务由轻作在后台托管，关闭工具页面不会中断。下载目录只能由你选择；任务记录和插件页面不会显示完整下载地址或本地路径。
- 插件 API 与 SDK 升级到 1.8.0。本版同时包含共享凭证库，旧插件和原有调用方式继续兼容。
- 旧版明文密钥不再使用。升级后请重新填写 AI、抠图、Seedance、希音等工具中已保存的密钥；凭据管理和共享凭证需要联网安装市场版工具后使用。

支持 macOS 15+ Apple Silicon、Windows 10+ x64。
