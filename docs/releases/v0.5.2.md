# 轻作 Qingzuo v0.5.2

- 优化超大屏幕（4K / 5K 及超宽带鱼屏）下的工作台与内置浏览器排版：解除右侧浏览器面板 1360px 的固定上限，按屏幕视口比例自适应展开（最高支持 2400px+），让 1688 等电商商品详情页与左侧插件工作区均有充裕的并排空间。
- 增强自适应宽度响应：拖拽分割线支持在大屏下自由伸缩至全屏比例，双击分割线即可一键重置为 48vw 黄金并排比例。
- 增加 3000px+ 超高分辨率视口断点，优化顶栏标签页、搜索栏与主内容区的平铺排版与留白，在大显示器下更开阔舒适。

支持 macOS 15+ Apple Silicon、Windows 10+ x64。
