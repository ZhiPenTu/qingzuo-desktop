# 轻作 Qingzuo v0.3.14

- 增加异常捕获与问题反馈能力：底座运行时自动收集未捕获的前端异常、服务调用失败与系统环境诊断信息。
- 全局异常防护与恢复：在顶层增加 React ErrorBoundary 保护，渲染层异常时提供友好恢复界面，支持一键重新加载与上报问题。
- 双入口快速反馈：在错误提示横幅及「设置 - 关于轻作」提供反馈入口，点击可一键唤起反馈对话框。
- 自动化 Issue 生成与剪贴板同步：支持一键在系统默认浏览器中打开预填好的 GitHub Issue 页面，并将格式化 Markdown 诊断信息自动写入剪贴板，方便用户无缝提交报错。
- 保持插件 API / SDK 1.2.0、现有配置和已安装插件兼容。

支持 macOS 15+ Apple Silicon、Windows 10+ x64。
