# 轻作 Qingzuo v0.3.2

- **插件更新超时修复**：大插件下载和安装改由后台任务执行，避免超过 30 秒后出现“内核请求超时”。显示下载进度、签名校验和安装阶段，切换页面后仍可查看状态。
- **更新冲突保护**：同插件更新期间阻止重复安装、启停、恢复和卸载；多插件完成安装时按顺序同步内核服务，无需重启应用。
- **失败恢复**：下载中断和签名错误显示实际原因并可重试；安装已经完成但内核同步失败时，只补做同步。安装失败保留旧版本，改进临时目录清理。
- **安全退出**：退出时取消未完成的下载，等待已开始的安装事务结束；重复退出请求不会跳过等待。

支持 macOS 15+ Apple Silicon、Windows 10+ x64。内置 CLIProxyAPI 8.0.23、Harness 0.2.1-alpha.1，插件 API / SDK 1.2.0；保留现有配置和已安装插件。

沿用 GitHub 未公证分发方式。回归验证使用隔离用户目录和本地签名响应，不发起付费模型请求。
