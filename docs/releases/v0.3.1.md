# 轻作 Qingzuo v0.3.1

- **AI 流式响应修复**：正确处理 UTF-8 分片、换行和多行事件，补齐生成参数、结束状态及错误处理；会话日志支持推理内容与 Token 用量的保存和回放。
- **工具调用与会话恢复**：长度截断的工具参数不会触发执行；恢复曾等待确认的会话时，旧授权不会重放，新调用仍需确认。
- **CLIProxyAPI 更新流程**：统一固定版本与制品哈希，支持官方发布检查、双平台下载校验、候选实际运行验证和依据报告采用版本；报告路径不能覆盖版本清单或验证证据。
- **Harness 升级验证**：统一整组依赖版本，支持隔离准备候选，检查依赖锁、公开接口、Node / Electron 原生加载器和旧会话兼容性。

支持 macOS 15+ Apple Silicon、Windows 10+ x64。内置 CLIProxyAPI 8.0.23、Harness 0.2.1-alpha.1，插件 API / SDK 1.2.0；继续使用现有 AI 连接配置和已安装插件。

推理与 Token 用量本次接入引擎和日志，界面展示及对话图片附件仍待后续接入。Harness alpha.2 要求新的原生加载器，须完成兼容审查后再采用。

沿用 GitHub 未公证分发方式。升级前建议备份配置和 AI 会话；自动化验证使用本地固定响应，不发起付费模型请求。
