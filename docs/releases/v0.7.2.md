# 轻作 Qingzuo v0.7.2

- 插件市场改为「全部 / 底座内置 / 官方社区 / 第三方」三档分类，并单独标明随应用内置、市场安装或本地导入来源。
- 凭证管理和文件下载器归入底座内置；其余已收录插件保持官方社区身份，本地导入始终作为第三方插件处理。
- AI 助手与日志调试从主界面拆分为独立第一方插件，可从市场安装；主界面仅在插件已安装且启用时显示对应入口。
- AI 对话、模型设置和密钥输入继续由桌面宿主保护，插件不能读取密钥、审批参数或工具调用详情。
- 调试日志在写入前统一隐藏密钥、令牌、密码和签名等敏感信息；日志插件首次访问时必须由用户明确授权。
- 插件 API / SDK 升级至 1.10.0，并收紧市场目录、发布片段和第一方插件调用校验。

支持 macOS 15+ Apple Silicon、Windows 10+ x64。
