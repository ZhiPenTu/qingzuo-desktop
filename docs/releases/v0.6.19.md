# 轻作 Qingzuo v0.6.19

- 新增自动更新，默认开启：启动后自动检查并下载新版本，之后每六小时再检查一次；设置里可以随时关闭，关闭后不再自动检查下载，这个选择会被记住。
- 更新状态写得更清楚：正在检查、已是最新版本、还没有可安装的新版本、更新已下载等待重启各有对应提示；下载时能分辨是在下完整安装包、差量包还是补齐组件，还可以清理过期更新缓存。
- 更新准备好后由你决定什么时候重新启动，界面会提醒先保存正在编辑的文件，不会在下载完成时自动打断你。
- AI 对话历史栏更好用：正在处理的会话会在名称里标出「（处理中）」，删除当前会话后焦点回到「新建对话」，读屏不再重复播报连接状态。

支持 macOS 15+ Apple Silicon、Windows 10+ x64。
