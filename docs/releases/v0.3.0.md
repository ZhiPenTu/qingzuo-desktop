# 轻作 Qingzuo v0.3.0

- **共享 AI 设置**：分层配置文本助手、账户与 API、图像编辑和代理连接；内置 CLIProxyAPI 固定 v8.0.23 并校验 SHA-256，也可连接外部代理。支持 Codex、Claude、Antigravity OAuth 登录及模型发现、连接和工具调用测试。
- **AI 对话与插件调用**：接入 DeepSeek Harness 0.2.1-alpha.1，支持流式对话、历史会话恢复、停止及工具调用。复用上游界面原语；插件操作展示冻结参数并等待用户确认，图像生成不会未经确认启动。
- **AI 批图底座**：新增多选原图、输出目录授权、并发批处理、后台执行和任务持久化。退出后手动恢复未开始项；状态未知的生成请求不自动重发，保存失败可重新保存已有结果。
- **CLIProxyAPI 图片模型**：独立「AI 批图」插件可复用已配置的代理账户，发现实际 GPT Image、Gemini / Nano Banana 图片模型及声明图片能力的兼容别名。保留 Google / OpenAI 官方 API；批次冻结来源、型号、参数和逐图提示词，不静默降级。
- **插件 API / SDK 1.2.0**：以不透明任务和目录标识提供 AI 能力，凭据由可信宿主管理并保持插件隔离；现有插件继续兼容。AI 批图 0.1.0 独立发布并通过工具市场安装，不随底座预装。

## 使用

**系统要求变更：macOS 最低版本为 15（Apple Silicon）**，以保留经过 SHA-256 校验的 CLIProxyAPI v8.0.23 官方制品。macOS 14 请继续使用 v0.2.9；Windows 仍支持 Windows 10+ x64。

升级底座后，打开「AI 设置」配置连接，再从工具市场安装「AI 批图」。选择图片来源、型号及提示词，先准备方案，确认并授权输出目录后执行。外部代理账户管理仍使用原管理端。

## 验证与限制

自动化使用固定响应，不产生付费图像请求；发布流程分别构建并检查 macOS arm64、Windows x64 安装包。独立插件另以固定底座制品验证上传、结果解析、助手方案确认及多图保存。此前本地已通过 118 项自动化与 macOS 安装包固定响应验收。

真实账户仅验证了本地代理模型目录，未使用账户进行付费图片生成或真实 OAuth 全流程验收。目录中的型号不代表账户已开通图像编辑权限；认证、限流和无图响应会显示失败，不自动切换型号。外部代理上游的重试、费用与额度策略由其管理端控制。

沿用 GitHub 未公证分发方式。升级前建议备份配置及 AI 会话；Harness 保持固定版本，后续升级先运行兼容契约和会话迁移验证。
