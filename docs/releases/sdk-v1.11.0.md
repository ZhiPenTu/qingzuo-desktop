# Plugin SDK 1.11.0

- 运行时插件 API 升级至 1.11.0，继续兼容声明更早 API 范围的旧插件。
- MCP 权限扩展为发现全部工具并按服务器与工具逐项授权，可调用会执行外部操作或产生费用的工具。
- `readOnlyHint` 仅作为服务声明展示，不再作为安全边界；授权、撤销、停用、卸载和退出会取消在途调用。
- `mcp.call` 新增可选 `inlineImages`，由主进程下载并转换图片，支持 `structuredContent` 返回。
- 宿主继续限制私网访问、重定向、参数与响应大小、并发和超时，并支持本机 Streamable HTTP 服务。

需要轻作桌面版本支持插件 API 1.11.0。现有插件接口保持兼容；使用通用 MCP 工具或图片回填的插件必须声明 `api: "^1.11.0"`。
