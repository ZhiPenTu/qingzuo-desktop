# 轻作 Qingzuo v0.3.12

- 界面文案更贴近日常使用：更新、插件、AI 对话与设置页面去掉只写给开发者看的说明，改成你能直接照着做的表述。
- 更新卡片更清爽：版本号与更新状态并排显示；「更新前请先保存正在编辑的文件」只在你确实可以更新时出现，不再常驻。
- 插件卡片状态更易读：版本、启用状态、可更新、缺少组件改为分色标签，一眼看清每个工具的状态。
- 下载源与自定义镜像说明改写为可操作指引，填错地址时直接告诉你该怎么填。
- AI 对话与 AI 设置不再暴露内部运行时名称、原始调用标识和技术字段说明。
- 提示语在功能正常时保持安静，只在出错、需要你操作或你主动查看时出现。
- 保持插件 API / SDK 1.2.0、现有配置和已安装插件兼容。

支持 macOS 15+ Apple Silicon、Windows 10+ x64。
