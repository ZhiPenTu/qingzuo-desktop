# 轻作 Qingzuo v0.3.7

- 移除内置代理运行时、OAuth 账户登录和相关更新/验收链路，统一保留外部 OpenAI 兼容代理连接能力。
- 新增下载源管理，支持内置源、自定义镜像与自动回退，并接入插件目录、插件安装和应用更新流程。
- 中性化外部代理适配器与错误文案，补齐下载源、平台和发布流程测试；CI 工作流升级到 Node.js 24。

这是一次包含不兼容变更的小版本更新：历史会话中使用旧 `cliproxy` provider 标识的记录将无法恢复；已配置的外部代理地址与访问密钥不受影响。

支持 macOS 15+ Apple Silicon、Windows 10+ x64。插件 API / SDK 仍为 1.2.0；保留现有配置和已安装插件。
