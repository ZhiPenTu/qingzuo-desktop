# 轻作 Qingzuo v0.3.17

- 在工作台增加内嵌浏览器工具标签，支持多标签页、地址栏、前进、后退、刷新和网页弹窗转内部标签。
- 浏览器使用独立持久化 session，保留站点 Cookie 和存储，同时与插件 session 的网络隔离保持分离。
- 浏览器直接使用 Electron `WebContentsView` 和 Chromium，不引入独立浏览器内核，随 Electron 上游版本获得更新。
- 调整侧边栏折叠按钮位置，避免覆盖品牌图标。
- 保持插件 API / SDK 1.2.0、现有配置和已安装插件兼容。

支持 macOS 15+ Apple Silicon、Windows 10+ x64。
