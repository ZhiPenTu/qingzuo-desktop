# 0.3.0 本地预览（未发布）

本次仅交付 macOS arm64 本地安装包和 `official.ai-image` 0.1.0 插件。暂不创建 GitHub Release、标签、SDK 公共发布或市场条目；不替换已安装的 0.2.9。

## 功能

- SDK / 插件 API 1.2.0：多选图片、目录授权、批图任务、助手会话和事件。原有插件接口保持兼容。
- 官方 Google / OpenAI 图像适配器，模型与参数按选择固定，无静默降级；统一和逐图提示词、单图试运行、并发 1–4、失败手动重试、逐张保存。
- 批图可复用外部代理的图片模型：按实际目录发现 GPT Image、Gemini / Nano Banana 及声明为图片能力的兼容别名。模型刷新不生成图片，不改变默认文本助手；官方 API 入口保留。批次冻结来源，代理地址变化时要求重新准备，不静默切换接口或型号。
- 宿主持有批次，关闭插件后继续运行。输入与生成结果私有持久化；保存失败不重新生成。退出后重新授权目录恢复未开始项，状态未知的请求不重发。
- 设置中的共享 AI 模型：连接外部 OpenAI 兼容代理服务，填写地址与访问密钥，支持模型发现与工具调用验证。
- DeepSeek Harness 包族固定 0.2.1-alpha.1；通过公开服务接口运行助手、规划工具、后台任务和 JSONL 会话恢复。助手仅可查询批次与修改草稿，不能启动图像请求。

## 本地使用

通过随包启动器启动独立预览配置；工具中心导入 `.ecplugin`。侧栏「AI 设置」按配置概览 → 文本助手（代理连接 / 默认模型）→ 图像编辑分层，每次只显示当前层。代理连接必须显式保存；图像型号不能被选为文本助手，不静默修改已有型号。图像页打开插件独立配置；插件顶部弹窗保存密钥仍保留队列。

新增工作台「AI 对话」：支持多个本机会话、流式回复、停止、恢复和工具调用结果；直接复用上游 Harness Markdown、JSON 参数树和活动组件。助手发现已启用插件后请求调用，每次展示插件及冻结参数，用户确认才执行。AI 批图可查询批次、修改方案、确认生成与停止；其他本地插件通过清单声明工具扩展。图像生成还需明确确认型号、逐图提示词与费用，并授予输出目录。详见 [Harness 适配与升级契约](../harness-integration.md)。

模型名称不代表当前账户已开通权限。服务拒绝型号时显示错误，不替换为其他型号。正式发布前仍需使用配置好的官方账户验证最新型号及参数和真实多图结果；本地自动化使用固定响应，不产生付费图像请求。
