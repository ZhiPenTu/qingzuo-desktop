# 轻作 Qingzuo v0.4.0

- 插件 API 升级到 1.3.0。插件可以申请页面自动化能力，在右侧并排浏览器中打开白名单内的页面，读取结构化节点，并执行点击、输入、选择、滚动和等待。
- 新增页面来源白名单与资源转存。插件只能操作清单声明的来源；图片等资源可借助该标签页的登录态转存。页面 HTML、Cookie、隐藏输入和密码字段始终不进入插件。
- 新增宿主侧请求签名与受控请求头。密钥不离开主进程，插件只能使用清单里声明的凭据与头名。
- 新增插件持久化存储。数据按插件隔离，卸载时连同凭据与浏览器分区一并清除。
- 插件打开浏览器时，右侧面板自动展开，可与插件页面并排使用。

旧插件不受影响；声明 `api: ^1.3.0` 的插件需要本版本。

支持 macOS 15+ Apple Silicon、Windows 10+ x64。
