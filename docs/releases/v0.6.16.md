# 轻作 Qingzuo v0.6.16

- 重新设计工具中心：标题、搜索与浏览器入口同排，页签、插件更新状态和导入入口集中在同一行，不必再为一行状态留出整条横幅。
- 工具卡片改为图标、说明、状态与操作四段结构，说明独占整行、最多三行且不再被截断；版本、启用状态与来源合并为一行安静文字，只有可更新、缺少组件这类需要注意的情况才强调。
- 工具网格宽度自适应，窗口越宽显示的工具越多，卡片始终保持易读宽度；窄窗口改为单列。
- AI 对话新增常驻的历史对话栏，可新建、切换和删除对话；窗口较窄时自动收起为抽屉。

支持 macOS 15+ Apple Silicon、Windows 10+ x64。
