# Plugin SDK 1.8.0

- 运行时 API 1.8.0。
- 新增宿主托管的 `client.downloads`：HTTPS 链接探测、最多 4 路 Range 分片、普通下载回退、目录授权、暂停/继续/取消/清理与跨重启续传。
- 新增清单权限 `permissions.downloads: 'use' | 'manage'`。`manage` 仅适用于市场或内置插件，可管理全局目录、并发和全部任务。
- 任务快照不向插件返回完整下载地址、查询参数或本地文件路径。
- 继承 API 1.7.0 的共享凭证库与 `{ record }` 网络凭据引用，保持文件、网络、浏览器、存储和 AI 接口兼容。
