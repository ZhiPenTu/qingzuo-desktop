# 轻作 Qingzuo v0.3.3

- **内核版本信息**：设置页显示内置 CLIProxyAPI `v8.0.23` 和 Harness / DeepSeek 内核 `v0.2.1-alpha.1`，并提供兼容性说明。
- **CLIProxyAPI 更新检查**：新增“检查 CLIProxyAPI 更新”，从官方 Release 获取候选版本和校验信息；当前候选仍需完成双平台 smoke、契约测试和制品哈希验收后，才允许用户态安装。
- **安全用户态更新基础设施**：CLIProxyAPI 更新服务支持版本化存储、SHA-256 校验、原子切换、健康检查、进度、取消、重试和失败回滚，不替换系统级运行时。
- **Harness 更新策略**：Harness / DeepSeek 内核随轻作安装包发布和升级，设置页提供“检查轻作更新”，不直接替换用户目录中的运行时。

支持 macOS 15+ Apple Silicon、Windows 10+ x64。插件 API / SDK 仍为 1.2.0；保留现有配置和已安装插件。

本版本完成更新检查和后台更新流程的基础接入。CLIProxyAPI 候选在双平台真实验收完成前不会显示“立即更新”，也不会被直接安装。
