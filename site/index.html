签名与校验

市场下载会校验签名、平台、身份与版本；安装失败自动恢复原版本，管理页可显式回退。

沙箱隔离

插件代码运行在隔离上下文中，系统级能力单独授权，出问题也波及不到底座。

自带 AI 能力

AI 对话与批图接入你自备的 OpenAI 兼容服务，地址与密钥在「AI 设置 → 代理连接」里填写。

应用内更新

设置页直接检查新版本并增量更新；安装包也支持缓存清理与磁盘空间回收。

插件 SDK

插件 API / SDK 1.2.0 与运行时 API 1.2.0，附带开发文档与独立测试入口。
